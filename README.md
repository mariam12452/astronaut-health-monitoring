# Astronaut Health Monitoring System

## Project Overview

The Astronaut Health Monitoring System is a software prototype developed in response to the NASA Space Apps Challenge 2026 challenge, "Create Health Monitoring Software for Astronauts on Space Missions."

The project explores how physiological data collected from astronauts can be monitored, interpreted and presented in a way that supports health awareness and decision-making during space missions.

## Problem Statement

Astronauts on long-duration space missions are exposed to environmental and physiological conditions that can affect their health.

Continuous monitoring of relevant physiological indicators can help identify deviations from an astronaut's normal patterns and support timely attention when necessary.

## Proposed Solution

Our proposed solution is a software-based health monitoring and decision-support system that analyses physiological measurements against individual astronaut baselines.

The system aims to:

- Receive and organise physiological measurements.
- Compare readings with individual baseline patterns.
- Identify unusual or persistent deviations.
- Present understandable health-monitoring statuses.
- Display trends over time.
- Provide explanations to support informed follow-up.

## Project Scope

The initial prototype focuses on selected physiological indicators associated with the Bio-Monitor system.
