# Project Overview

## 1. Project Background

This project was developed in response to the NASA Space Apps Challenge 2026 challenge: "Create Health Monitoring Software for Astronauts on Space Missions."

The challenge focuses on the need for accessible and useful health-monitoring tools during space missions, particularly as astronauts experience physiological changes associated with the spaceflight environment.

## 2. Project Aim

To develop a software prototype that receives physiological measurements, evaluates deviations from individual baseline patterns and presents relevant information through an accessible monitoring interface.

## 3. Project Objectives

The proposed objectives are to:

- Identify relevant physiological indicators for astronaut health monitoring.
- Establish a structured approach to receiving and organising measurement data.
- Develop a method for comparing readings against individual baselines.
- Identify unusual or persistent changes in physiological measurements.
- Present monitoring results through an understandable dashboard.
- Support informed follow-up without attempting to provide medical diagnoses.

## 4. Intended Users

The intended users include astronauts and authorised personnel involved in monitoring astronaut health during space missions.
